# Host display

The big-screen view. Runs full-screen in a PC browser plugged into the TV (primary), or mirrored from a phone via AirPlay/Chromecast/Miracast (fallback for no-PC setups).

Responsibilities:
- Show the room code for players to join.
- Play the current clip with all identifying YouTube UI hidden.
- Show the scoreboard and round state.
- Never render the answer before the host reveals it.
