# Player controller

Opened on each friend's phone. Joins a room by code and acts as a buzzer/answer pad — this is not screen mirroring, it's a lightweight input device synced to the host via Firebase.

Responsibilities:
- Join a room by code, no login required.
- Buzz in / submit an answer for the current round.
- Show only the player's own state, never the answer key.

Not built yet — see `docs/PLANNING.md` for the build order.
