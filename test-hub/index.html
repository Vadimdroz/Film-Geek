🧪 Film-Geek Test Hub

Dev-only tool for playtesting new functionality against a fixed room code. Writes to the same live Firebase project as real games — everything here is scoped to room TEST only.

1. Seed the test room

Creates room TEST using your real tagged clips, plus two fake teams (score reset to 0 each time). Re-run any time to reset for a fresh test.

2. Open test windows

Open the host link in a normal tab — same browser profile, so it auto-resumes room TEST. Open each team link in its own incognito/private window, not just another tab: regular tabs of the same browser share one anonymous identity, so two "teams" in regular tabs would collide.
